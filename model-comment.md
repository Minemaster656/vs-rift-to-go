Исходная модель бутылки универсальная и для тир 1-3 бутылок и для заполненных, и для колбы очищения и для бэд трип бутылки / портативной колбы очищения

Модель состоит из следующих частей:
корень - просто корень (folder):

- внешняя стенка бутылки // 1
- внутренняя стенка бутылки // 2
- крышка // 3
- разлом (folder):
- - ядро разлома // 4
- - аура разлома // 5

(// - пометка номера текстуры в блоке ниже про текстуры)
